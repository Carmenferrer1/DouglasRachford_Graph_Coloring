# DouglasRachford_Graph_Coloring
Python implementation of the Douglas-Rachford algorithm applied to graph  coloring problems via rank formulation. Used as a heuristic to solve Sudoku  puzzles modeled as graph precoloring problems. Developed for a Bachelor's  Thesis in Mathematics, University of Alicante (2025-2026).
Three numerical experiments are included:
- Experiment 1: 50 Sudoku puzzles from Project Euler (Problem 96)
- Experiment 2: Comparison of operators and parameter lambda values
- Experiment 3: One million Sudoku puzzles from the Kaggle dataset
